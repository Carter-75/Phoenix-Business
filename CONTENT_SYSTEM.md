# Content system
Status: 30 scripted concepts, not recorded videos. All public publishing requires approval. Day 1 means the first approved publishing day, not today.

## Primary approach
Make practical content for website buyers. Use simple before/after demonstrations and inquiry-path tests. A broad AI entertainment channel has weaker direct audience fit and adds production work. This is a positioning judgment, not a measured conversion claim. Use one business-related AI episode as a small comparison after four buyer videos. No separate entertainment-channel spend yet.

## Production plan
Record four 4–6 minute source videos on days 7, 14, 21, and 28. Each combines the preceding six short lessons with a demonstration. Use the scripts below as narration modules. The long-form versions still need recording, transitions, and editing; they are outlines assembled from finished short scripts.
Publish one short per calendar day if production capacity permits. Prefer three strong shorts per week over rushed daily output. Reuse clean vertical exports for Shorts, Reels, and TikTok. Turn each lesson into a LinkedIn text post. Share in local groups only when their rules permit promotion. Do not post identical pitches across groups.
All items use one offer: the free website audit. Link format after deployment: https://phoenixwebsites.ai/website-audit?utm_source=youtube&utm_medium=organic_video&utm_campaign=buyer_audit_30d&utm_content=d01 . Change source for each platform and day code for each item. No link is live-approved merely because it is written here.

## Common edit specification
Vertical 1080x1920, 30–45 seconds for shorts. Open with the exact hook. Use a real screen demonstration or clearly labeled demo. Show readable captions, keep key text away from app controls, and check audio on phone speakers. End with: “Want three practical fixes for your website? Request a free audit from Phoenix. Link in the description.” Caption text equals the approved narration; the editor exports an SRT after timing it to audio. A description caption can use the lesson plus the tracked link. Never imply Phoenix built a prospect’s site.

State your fixed price, turnaround, editing tools, and relevant examples.

[Upwork’s cost page](https://www.upwork.com/hire/video-editors/cost/) lists a wide rate range and an entry-level median around $10/hour.
